# Visual direction

Keep narrative genre, production format, visual aesthetic, spoken language and prompt language as separate choices. Ask only when a choice changes the result substantially; otherwise state a reversible assumption. English is the default prompt language; retain supplied dialogue in its original language. Automatic density chooses the least detail that covers the shot; Maximum is experimental and never automatic (`references/density-and-budget.md`).

Do not invent story events, character relationships, era or locations the user did not supply; label a creative assumption if one is needed. Build a reusable look from light direction and quality, contrast, color, lens and depth, texture, wardrobe, makeup and the treatment of faces. Anchor character appearance and the setting to the appropriate references. Keep shot-specific light changes motivated and compatible with continuity. Respect the selected aspect ratio; no genre requires vertical framing.

## Optional polished East Asian short-drama look

Use only when selected or supported by the brief. Describe the actual traits, not a celebrity or a blanket requirement: cinematic shaped lighting, refined makeup, luminous natural-looking skin, controlled highlights, flattering but believable shadows, deliberate color and stable faces, hair and wardrobe. Adapt the treatment to the characters and scene. This aesthetic can be used with any genre, production format, spoken language or prompt language; none implies it automatically.

For a project look or reference, state what it governs. For a shot, add only changes needed to tell the story. Check the approved storyboard and continuity ledger before generating a reference image or final prompt.
